## What changes for the learner

- A fresh GPT conversation can resolve a project by name, show a Journey overview of distinct task activity, and read the relevant exact task. Small linked Notes, newer edits, Annotations, bookmarks and external-evidence pointers appear alongside deliberate checkpoints with their own authority, dates and exact references. Ambiguity asks for a choice; no automatic checkpoint or read receipt is added.
- Notes have a deliberate **Insert terminal output** action. Prediction and interpretation remain normal prose around a compact semantic block. Blocks can expand, copy exact output, edit, remove and reopen. Console bytes are untrusted data and carry external-evidence provenance. Pending inserts/replacements are retained individually; size rejection keeps pasted text.
- GPT deliberately saves the same block through `data.noteContent`, using ordinary guarded Note commands. Routine context contains a small preview/pointer; `read_minamo_record` with `terminalId` retrieves exact output separately. Existing revisions, CAS, immutable-operation recovery and markdown-v1 Notes remain the authority.
- A Note captured from a task's supporting reading preserves **both** the exact reading destination and the originating task. Context links navigate through the shared workspace; later reading changes cannot silently retarget the Note. Journey/stage/Investigation activity and the Task rail show recent thinking separately from saved checkpoint actions.
- Search shows the actual eligible matched field/passage and exact destination. `Rust` inside `trust` is honestly labelled a substring; a later whole-token occurrence provides a better snippet. Unicode prose matching, technical aliases, source rights and pagination are preserved. There is no embedding service or semantic relevance claim.
- Occasional goal-first authoring now explicitly prepares an anticipatory reusable Library with the practical Journey and Investigations. A **Start a Journey with GPT** entry prepares a copyable goal request; an explicitly authored **Start working locally** stage gets a direct route. The publisher retains bounded bulk creation, exact reuse and targeted expansion. Errors identify fields/limits; a committed targeted-publication retry now recovers its receipt before stale-revision compilation.
