- Every source-browser block now offers a deliberately activated CodeMirror scratch editor, separate immutable starter, per-file reset, exact UTF-8 hashes, complete starter/submission comparison and regenerated scratch ZIP. Original Windows CRLF input uses an explicit CodeMirror line separator. Editor loading failure leaves a plain-text fallback.

Pending requests freeze the payload; source, test and checksum mismatches reject. - Changed visible tests are called out during editing and in comparison. Saved submissions re-read the retained starter under current rights before displaying test integrity. No code executes in the Minamo editor and no claim is promoted from supplied output to observed execution.

A connector observation relayed by GPT remains `supplied-unverified` inside Minamo; an unkeyed receipt digest is not authentication.
- Three original source-bound computing compositions are available from `computingPracticeExemplars`: shell argument/stream reasoning, TCP process/socket/EOF reasoning and counterexample/test-failure repair. Exact starter file hashes bind the finite illustrative steps; imported code is never executed by stepping. These are parallel teaching examples with no Bandit credentials or live-level solutions. Publishing the factory's output is a separate explicit authoring action.
- The shared Activity host mounts typed practice, listening, character and scenario controls. Deliberate general Attempt saves retain character/scenario interactions; component-owned saves handle structured responses and dictation. No interaction creates a formal checkpoint.
- Atlas retains lens, exact record focus, kind/relation filters and expanded groups in bounded URL presentation state. Browser Back/reload preserves it without storing source text. Existing workspace history state is preserved.
- A large unfocused workspace begins with collapsed groups instead of fitting every stage into one unreadable map. Stages stay with their actual Journey; deliberate expansion exposes references and a direct canonical source link remains available. Focused maps and the accessible card list share the same current graph.
- Exact source links include typed practice sources, character context and aligned listening transcripts. Explicit saved corrections project as separate nodes with current revision/status/modality and retained Attempt links; disputed or withdrawn feedback is never labelled current teaching authority.
