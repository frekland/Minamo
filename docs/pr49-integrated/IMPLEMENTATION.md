## Validation and known limits

See [authoring/handoff](AUTHORING-HANDOFF-ACCEPTANCE.md), [language contract](../learning-spaces/LANGUAGE-READING.md), [Foundry activation](../commissions/PR49-PRACTICAL-FOUNDRY.md) and the implementation PR's dated release comments. Focused tests use the real compiled domain with isolated Miniflare D1/R2, exact MCP, native-DOM lifecycle and actual compiled Workspace components. These are distinguished from production authentication, cloud browser gestures and physical hardware.

Independent reviews corrected source-only cross-paragraph copying, malformed scalar admission, lost scope in copied links, pre-LIMIT filtering omissions, classification race/cursor behavior, historical archive validation and query-budget regressions. Full required typecheck/build/test counts and native/GitHub tree identities are bound to the final candidate in its release receipt.

The supported local preview advertised `http://terminal.local:4173/` but the cloud browser received connection refused and a direct request timed out. One supported stop/start did not establish reachable preview; no alternate browser host, network permission or server was invented. Authenticated production browser acceptance is separate. Physical Pixel8a/IME/TalkBack and new-human-Chat checks cannot be inferred from desktop or synthetic tests.

Scientific Python execution, tldraw and heavy GPU/audio/untrusted runtime lanes remain gated. The scientific bank retains pinned offline code but lacks qualified phone memory/performance and complete durable-output authority acceptance; the presence of a tldraw key does not establish licence/device readiness. Their absence does not block the qualified core release. No dependency was added.
