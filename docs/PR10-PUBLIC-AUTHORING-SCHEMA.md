# Public routine authoring schema

The routine append tool publishes a concrete root object and a content array
whose `anyOf` alternatives each declare their own `kind`, permitted properties
and required fields. These alternatives reuse the canonical field schemas;
they do not use conditional `allOf` intersections or an untyped payload.

Paragraphs and code require text; callouts require text and callout metadata;
tables, images and media require their typed payloads; references and excerpts
require their exact metadata and text; interactive parts require text and the
existing typed interactive payload. Structured and legacy text diagrams have
separate alternatives. All variants accept an optional ID generated by Minamo
when omitted. Existing semantic/inline fields remain available where applicable.

This module is a public schema adapter over the established canonical writer.
It adds no new persistence representation or educational classification. Server
validation remains responsible for exact rich content, source rights, revisions,
protection locks and Note restrictions. The backend retains advanced-request
compatibility; explicit composition is also available through existing tools.

The tools/list regression inspects every public content alternative, its kind,
required properties, optional IDs and strict object boundary. The existing
routine append preview/apply/replay tests exercise the same server path.
ChatGPT's conversion of the schema remains a separate fresh-connector acceptance
check performed by the owner after deployment.
