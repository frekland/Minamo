# Earlier Project-reader first slice — superseded

**Status:** Historical, not a live implementation commission.

The first drafts of PR #12 proposed cleaner Project navigation and optional related-passage comparison. The owner subsequently identified the central product constraint: **a useful interaction or explanation must be retainable without being assigned to a Project or Library**, and GPT should be able to assemble existing material into a useful experience later.

The authoritative, cross-product proposal and staged plan is now [Minamo: accumulate independently, compose experiences on demand](MINAMO-ACCUMULATION-AND-COMPOSITION-RFC.md).

Existing Project reading remains important and should not regress. Its prior requirements—clear first view, no clutter, authentic source identity, usable Japanese/code/interactive content, responsive navigation, and truthful continuity—remain relevant to any future reader implementation **where supported by the new source/arrangement model**. Do not implement or deploy the former Project-only work as though it satisfies PR #12.

The original full specification is preserved in Git history; this redirect prevents two competing instructions in the active draft PR.
