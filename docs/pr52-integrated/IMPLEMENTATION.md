## Deliberately qualified boundaries

- The custom, versioned spacing algorithm is **minamo-spacing-v1**, not FSRS and not a proficiency estimate.
- Character geometry teaches a small attributed imported subset and accepts further bounded validated data. It is not an exhaustive Japanese/Chinese character dictionary or historical-etymology authority.
- Actual human speech fixtures qualify meaningful playback/transcript mechanics. Real microphone/stylus/physical IME/assistive-technology behavior and native-speaker certification remain separate from desktop browser or synthetic event tests.
- Canvas stays gated: a supplied tldraw licence alone does not qualify a private production own-shape persistence/privacy flow.
- Imported code remains inert. A broader separate-origin dependency-bearing preview remains gated; useful exact local/GitHub exchange is delivered independently.
- GitHub connector information relayed into Minamo remains supplied-unverified. Exact commit/compare/local execution evidence is useful, but no unauthenticated model payload is promoted to independent Worker/provider verification.
- Publication and model review do not create learner achievement. No real Bandit answers, credentials or level solutions were added.

6. Starting unassisted character recall now clears old visible ink while retaining event history.
7. Browser measurement found inherited form margins still inflating the compact header. Header-specific label/select margins and line height were corrected.
8. Existing tests with frozen policy/catalogue versions were updated to the new deliberate versions. Compiled Worker tests run against the actual production build; remote GitHub CI is not substituted or represented as green.
