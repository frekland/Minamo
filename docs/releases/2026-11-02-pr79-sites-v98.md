- **MCP:** Production deployment reported `has_mcp:true`; two read-only page WebMCP operations succeeded (`get_my_workspace` returned a bounded envelope and `search_my_library` returned search records). The older typed GPT/MCP continuity contract also has local scenario tests; no independent full new ChatGPT conversation/save was performed during this release check.

The four files were rerun individually to classify the broader-suite failures:

- `tests/library-route-state.test.mjs`: the multilingual cursor fixture inserts three records with `synthetic:true`, but the ordinary Library browse correctly excludes synthetic records after PR #79, so the expected three IDs are now an empty list.
- `tests/library-runtime-regression.test.mjs`: two cases similarly assume synthetic records appear in Library reference search and authored Subject membership; the API now excludes them and falls back to title order where no eligible authored Subject exists.
- `tests/pr26-learning-interface.test.mjs`: an older authenticated HTTP fixture creates only synthetic Library Articles and expects one to appear in ordinary search, now excluded by the same policy.
- `tests/page-entry-priority.test.mjs`: an esbuild test adapter does not supply a `.css` loader; the new Study/Activity CSS imports cause the test bundle to fail with 20 CSS import errors. This is a test-harness configuration failure, not a production build failure (the native production build passed).

These are **diagnosed test-fixture mismatches**, not evidence that the learner flows passed the full suite. The test fixtures/harness still need maintenance and a full-suite green rerun. The opt-in release does not count as final product acceptance.

- A responsive mobile browser viewport and a brand-new hosted GPT conversation that saves a Note were **not** independently exercised; successful WebMCP reads and existing local typed tests do not establish those end-to-end behaviours.
- No owner fixtures, Notes, Attempts, Work, database records, secrets, access policies, host environment variables, or external Cloudflare deployments were changed by the release or acceptance walkthrough.
