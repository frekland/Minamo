# Notes, Trash and navigation correction

Notes: the mobile first-child flex selector stretched the context label instead of the writing wrapper. The corrected layout gives the rich or source editor the available sheet space. The editor loader retries rejected imports, including failures before codec initialization. Code and image controls are directly in the toolbar; image pick/drop validates, stages privately and inserts into the originating Note through the existing autosave and revision protocol. Plain/fallback source insertion remains supported. The mandatory image metadata form and duplicate bottom image uploader are removed. Existing exact source, terminal and pending-image recovery guards remain.

Navigation: sidebar knowledge areas and Sources shortcuts are removed; Library subject browsing and source records still exist. The existing Investigations list sorts by the newest creation or eligible saved checkpoint, excluding unrelated editorial updates. A separate scoped lightweight index avoids omissions from workspace pagination and scans complete bounded checkpoint history, with explicit budget errors rather than silent truncation.

Empty Trash: authenticated GET creates a current-generation identity/revision snapshot. POST permanently deletes only that confirmed, still-trashed set in one guarded batch, preserving active/restored/concurrently changed records and other owners. A simple Yes/No dialog precedes the operation. An uncertain result retains the exact operation request; replay cannot resurrect deleted work or delete newly trashed records. Current records, revisions and associated per-record database rows are removed; content-bearing operation receipts are scrubbed. Unreferenced all-purged manuscript sources are removed while preserving the immutable-delete trigger transactionally. Mixed original manuscript packages needed by active siblings and existing recovery backups are separate historical artifacts and remain. This feature does not automatically empty real production Trash.

Validation: focused actual D1 tests cover ordering beyond recent pages, privacy/generation/source boundaries, purge/replay/stale snapshots and atomic rollback including trigger restoration. Editor tests cover loader retry, codec/history, persistent hosts and image continuity. Browser preview confirms rich editor initialization and direct toolbar controls. Final aggregate results, source-tree correspondence and private deployment identities are recorded in the implementation PR. No real Trash purge or learner-content alteration is part of release acceptance. Rollback is private V48; a future owner-confirmed purge itself is permanent in the current database.
