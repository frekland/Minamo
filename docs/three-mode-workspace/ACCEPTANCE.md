## Defects found and corrected

Independent reports contain the source dispositions. Browser-only discoveries included: still-dense mobile orientation; Technical/Classic/Task mobile prose overriding Largest; a compact Task rail which did not meaningfully collapse its body; and an invisible native reading GPT modal after another tab changed layout. Corrections keep explicit disclosures, honour shared size variables, retain an actual compact Task body, and preserve open modal ancestors before paint. The modal regression was replayed successfully with question/selected resource intact in Focus and Task; component rendering tests alone had not exposed it.

A further exact-source review found stale captureA could resolve requested captureB before the next effect. The new capture-key/family/ID guard rejects that projection; permanent tests cover same-record and same-ID/different-family transitions. The resolved exact reading now jointly gates Reader, reading GPT, contextual Notes and presentation memory. The newly integrated discussion-focus helper uses the Reader's actual UTF-16/source validation.

QA infrastructure corrections are not product defects: full source sync restarts development configuration and initially produced lost preview connections; the supported preview was restarted after sync, without network/security changes. Removed research CSS required a QA-only viewport frame (production has none). The inherited test allowlist initially omitted checkpoint`revise`, and its bootstrap omitted capture props on reload; the external helper now forwards them and permits only that existing revise route. Corrected workflows were rerun. Some immediate post-reflow screenshots timed out; settled captures succeeded. No UI success is inferred from a failed screenshot.

## Explicit limits

- Local authenticated-principal substitution is test infrastructure outside production. No released multi-layout UI, native source push, Site save/deployment, access change or connected record mutation was made.
- No physical Android keyboard/TalkBack/touch handles, Windows/Kali terminal, separately authenticated owner profile, fresh GPT conversation, heap/latency/learning-gain or satisfaction benchmark. Same-browser preference propagation was real; mobile preference/draft scope is a fixture simulation.
- Shelf and mode-return slots are session memory; only preference/options and bounded semantic positions have the documented device/session storage. No unsaved cross-device sync. Raw pending image bytes still require reselect after reload under the existing Notes contract.
- Explicit deep links outrank remembered scroll. Semantic reload is exact-edition/session scoped; fallback part position and1.5s delayed geometry window are bounded, not arbitrary cross-device/late-content guarantees.
- A task request opened from the Task-only rail closes if an external preference removes that rail; its copied exact request remains unchanged. The shared reading-action dialog retains its editable question/selected context, with native visibility/focus verified. No learner writing or operation is owned by these ephemeral request dialogs.
