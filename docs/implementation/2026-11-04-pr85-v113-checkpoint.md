## Remaining — TTS checkpoint, not silently shipped

Optional browser-local neural speech is **not yet in V113**. The separately tested lab at `/workspace/sites/minamo-tts-lab` uses `@mintplex-labs/piper-tts-web@1.0.5`, `piper-plus@0.8.2`, and `onnxruntime-web@1.30.0` plus browser runtime assets. The required `pnpm add` operation stopped because its package-network approval was cancelled; the safer offline attempt lacked registry metadata. Do not bypass that permission boundary. Runtime copies prepared for evaluation were **not committed, uploaded or bundled** into Minamo.

Owner-approved architecture remains:
- Original Piper for individually verified non-Japanese voices; Japanese Piper Plus CSS10 only.
- Japanese Normal `lengthScale:1.6,noiseW:0.2`; Slow `lengthScale:2.4,noiseW:0.2`; synthesis time, not playbackRate stretching.
- On-demand, client-side inference and cache; never Web Speech, token-metered APIs, server inference or non-Japanese CSS10 modes.
- Source language text only, not translated glosses/furigana; no learner record changes.
- Verify package/phonemizer GPL/MIT components, each voice/model's actual terms (CSS10 model derivative/base attribution may apply), provenance, pinned URLs, CORS, sizes, memory, loading/offline and a Pixel 8a owner's listening judgement before live expansion.
