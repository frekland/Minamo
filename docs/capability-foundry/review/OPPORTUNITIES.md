Scores are independent reviewer judgement: educational breadth E, reuse R, low-effort activation L, offline confidence O, each 1–5. They are prioritisation hypotheses, not measured learner benefits. ## Verified primary source ledger

Firecrawl search and page retrieval were performed for each category. Retrieval dates are 25 October 2026; cached metadata is recorded where supplied. Links are technical evidence, not copied lesson content or licences to reproduce third-party examples.

- N01: [RFC 4648](https://www.rfc-editor.org/rfc/rfc4648.html), actual page retrieval HTTP 200. Specifies base16/base32/base64 alphabets, padding and canonical encodings, with reference test vectors. Implication: label base64 versus base64url explicitly and reject illegal input under the chosen finite contract. Do not infer encryption or privacy from encoding.
- N02: [Git diff format](https://git-scm.com/docs/diff-format), retrieved HTTP 200 (cache 24 October); [Git merge](https://git-scm.com/docs/git-merge), search excerpt. Git distinguishes ordinary and combined diffs; conflict-marker forms can include a base section. Implication: do not parse every merge artefact as an ordinary two-column patch or silently resolve it.
- N03: [TC39 timezone documentation](https://tc39.es/proposal-temporal/docs/timezone.html), current retrieval now directs API readers to MDN. Historical search passages retained detailed ambiguity examples, but were **not treated as the current full page**. [MDN Temporal.ZonedDateTime](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal/ZonedDateTime) current retrieval labels availability limited. Implication: feature detect and disclose database/runtime dependence; a native browser prototype cannot presume universal Temporal support.
- N04: [WAI-ARIA 1.2](https://www.w3.org/TR/wai-aria-1.2/), full page retrieval HTTP 200 (cache 25 October). Defines roles, states and properties for accessible UI semantics. Implication: authored role metadata is not evidence that a particular AT will announce it correctly; keyboard and focus are separate behaviours.
- N05: [CSS Color 4](https://www.w3.org/TR/css-color-4/), retrieved HTTP 200 (cache 24 October), revision `a1dd3973e461e13cfe2d56a3513948882e595034`. Describes colour spaces and encoded versus linear-light representations. Implication: interpolate after appropriate transfer-function conversion, retain original numeric source, and avoid relying on an unmanaged display as a physical colour measurement.
- N06: [fast-check property-based testing introduction](https://fast-check.dev/docs/introduction/what-is-property-based-testing/), retrieved HTTP 200. Explains generated cases and counterexample shrinking. Implication: trace viewer can be dependency-free; executing a user test or asserting test success requires a genuine separate runtime receipt. No fast-check package installation or licence audit was performed by this review.

## Rejected expansion directions

- Browser remote-desktop/terminal access: would expand machine access and credentials rather than improve presentation of supplied learning evidence.
- Automatic learner scoring from interactions: conflicts with explicit evidence/checkpoint semantics and lacks educational validity.
- Real-time multi-user collaboration: substantial new ownership/concurrency authority with little justification for this personal workspace commission.
- General-purpose package/plugin execution: introduces arbitrary code and supply-chain access; typed finite adapters provide most of the immediate display value.
- Cloud vector retrieval/AI grading: recurring service and privacy implications, outside the no-paid-service boundary and unnecessary for these adapters.
