## Implementation contract

API: `dataTraceAdapter (`trace/external-v1`), admitTrace, redactTrace, FoundryTrace`. Paths: `lib/foundry/data-platform.ts; lib/foundry/data-core.ts; app/foundry-data-demo.tsx`.

```ts
dataTraceArtefact({format:"minamo.trace.v1",classification:"supplied-artifact",redacted:false,events:[{sequence:0,timeMs:null,kind:"command",text:"$ echo example"}]})
```

The shared `minamo.artefact.v1` envelope preserves exact canonical source plus SHA-256 and supplied/illustrative provenance. Admission reparses source and compares the visible payload; unknown fields, source mismatch, invalid format and computed-provenance elevation reject. Rights, generation, Trash, retained edition and receipt checks remain `ArtefactRegistry`/existing domain responsibilities; the renderer has no storage/identity authority. The adapter is lazy and its React mount returns unmount cleanup. Invalid/unsupported content keeps exact source outside the rejected rendering and returns actionable error/static text.
