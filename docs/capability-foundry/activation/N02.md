# N02 — Supplied unified-diff reading

Status: RUNNABLE_STANDALONE (React specimen and actual finite-engine tests); dormant and unreleased.

Problem: a learner wants to understand a small authentic code change without executing Git or applying an untrusted patch. `readUnifiedDiff(source)` returns a versioned `minamo.unified-diff.v1` object, supplied-artifact classification, original source, path labels and ordered hunks/line-number/source-offset entries.

Finite supported subset: one text file, ordinary unified hunks (optional `diff --git`/index/mode header), <=131072 UTF16 units,4000 lines,256 hunks. Counts and ordered ranges are validated; CRLF original offsets remain exact. Combined/binary/multi-file diffs, unknown metadata and malformed counts reject with retained-source fallback. File paths are display labels, including `/dev/null`; no path is resolved/read/written. No conflict resolution or patch application occurs.

Primary sources: [Git diff format](https://git-scm.com/docs/diff-format), actually retrieved, and [Git merge](https://git-scm.com/docs/git-merge) search excerpt. Wider conflict/combined formats were deliberately excluded to avoid false fidelity.
