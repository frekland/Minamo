# F09 — Deliberate pronunciation playback

**Status:** RUNNABLE_STANDALONE; browser local-voice enumeration UI is implemented, controller lifecycle is unit-tested. Actual usable Japanese speech, offline behavior and phone screen-reader coexistence need device acceptance.

**Source:** banked branch `research/foundry-execution-20261025`, final PR commit and `../language/SOURCE-MANIFEST.json`; `lib/foundry/language-speech.ts`, `app/foundry-language-demo.tsx`, speech tests inside `tests/foundry-language.test.mjs`.

**Contract:** `createLanguageSpeaker(port,notify)` exposes `voices(language,allowNetwork=false)`, `play(text,language,voiceURI,rate=0.85,allowNetwork=false)`, `stop`, `dispose`. At most 1000 UTF-16 characters and rate 0.5–1.5. Construction never speaks. Only an explicit gesture plays. Voices reported local are offered by default; absence is a clear disabled/fallback state. `browserLanguageSpeechPort()` returns null when unavailable.

**Dependencies/licence/assets:** browser SpeechSynthesis API, existing React only; no new packages, recordings, fonts or service. Source: [MDN utterance API](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance). Platform voices can vary and `localService` is a report, not a privacy/offline guarantee. No microphone/recognition or accuracy grading. Browser synth cancellation is global; a production integration should have one shared app-level speaker owner, not competing component queues.

**Evidence:** injected-port tests prove no autoplay, unavailable/remote voice rejection by default, explicit text/rate checks, stale completion suppression, stop/dispose once, removed voiceschanged listener. Lab UI works without a voice and labels synthesized speech. Cold/warm audio latency, speech quality, actual physical playback and memory are unmeasured. Source permissions must be checked before passing the current original text to play; dispose on unmount/rights loss. No speech text or score is saved.

**Rollback:** remove the default-off controls; source reading remains native text/ruby. No migration, scheduled task or external service cleanup.
