# F17 — Exact tokenizer proposals and human correction

**Status:** RUNNABLE_STANDALONE importer and real Node Kuromoji experiment. Full browser dictionary redistribution/worker execution is DEFERRED, not Light-ready.

**Source/API:** final foundry PR commit, `../language/SOURCE-MANIFEST.json`; `lib/foundry/language-tokenizer.ts` exports `proposeTokenizerReadings(text,observations,producer)`. Inputs use bounded `{surface_form,reading?,pos?,word_type}` observations; producer names exact package/version/dictionary digest. Token surfaces must concatenate to the complete original source. Offset derivation uses exact UTF-16 concatenation, never untrusted `word_position`. Unknown tokens get no invented reading. All proposals have `origin:machine-proposed`; `correctLanguageReading` performs deliberate immutable correction with expected prior reading.

**Measured experiment:** `../language/tokenizer-experiment.mjs` and `kuromoji-evidence.json`: kuromoji 0.1.2, 17,791,956 bytes compressed dictionaries, package unpacked41,263,301 bytes; Node24.22.1 init402.6ms; RSS60,928,000→408,784,896 bytes before/after. Six synthetic input cases ran. This is not browser/Android peak memory. Exact manifest hashes and registry integrity are in language results/evidence. No dictionary was added to product dependencies/assets.

**Choice/risks:** curated ruby stays preferable. Package Apache-2.0 wrapper plus separate [NAIST/ICOT dictionary notices](https://raw.githubusercontent.com/takuyaa/kuromoji.js/master/NOTICE.md). Ambiguous names and contextual readings are not reliable authority. Actual `小鳥遊` case split into known/unknown pieces. Default network/package loading would violate current execution assumptions; do not add it. Source rights/CAS remain existing domain. Importing external tokenizer output is supplied evidence, not a Minamo-observed runtime receipt or learning achievement.

**Validation/fallback:** 16 pure language tests include exact token surface, emoji offset, unknowns, omitted text and unsupported keys. Failed proposals leave original source unchanged with an actionable error. Fallback is curated original text. Rollback drops the optional proposal importer; no persisted source is rewritten.
