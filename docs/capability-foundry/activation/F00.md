## Contract and boundaries

`minamo.artefact.v1` has an exact canonical format/source/SHA256, strict kind/version, optional exact retained source ref, provenance and validated payload. `ArtefactRegistry.admit(input, authority)` snapshots/freezes JSON after finite byte/depth/node checks, then verifies current domain eligibility and trusted Run claims. Payload receipt fields confer no authority. `activate` loads one trusted internal module, rechecks rights before/after mounting and returns `dispose/revalidate`; denial clears source and fallback. Production must supply existing domain owner/generation/revocation checks, not a boolean from imported JSON. Views cannot stage assets, persist records, fetch source URLs or issue learning achievements.

API: `lib/foundry/platform.ts`, `digest.ts`, `core-adapters.ts`, `specimens.ts`; adapters live in language/math/data/audio/visual `*-platform.ts`. `sha256Text` uses native SHA256 with lazy `@noble/hashes`2.4.0 MIT fallback for HTTP-only local previews. Legacy crypto/permission mechanisms are unchanged. Whole source≤65,536 UTF16 units; envelope≤262,144 UTF8 bytes;18 nesting levels/20,000 nodes. Sparse arrays, accessor values, prototypes, nonfinite numbers, cycles and unknown fields reject. `minamo.run-outputs.v1` validates bounded text/table/private-PNG references, but never accepts/stages bytes or acknowledges a saved Run.

Tests: `node --test tests/foundry-platform.test.mjs tests/foundry-specimens.test.mjs tests/foundry-*-platform.test.mjs`; independent regressions in `review/adversarial-platform.mjs`. Revocation-after-load-failure and sparse-array attacks were independently reproduced/fixed. Twelve source-drift/ref-denial fixtures and SHA256 vectors compare an independent Node oracle. Current static fallbacks retain meaningful source. Gallery loading/cleanup browser evidence is separate in `../BROWSER-ACCEPTANCE.md`.
