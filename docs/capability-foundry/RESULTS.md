## Recommendation

Activate read-only explicit mathematical source and curated ruby first, then source-bound tables/traces, byte/diff tools and fixed algorithm illustrations when a real project calls for them. They have the clearest low-cost integration paths. Keep scientific execution dormant until a practical need and physical-device acceptance justify its package/memory burden. Keep browser dictionary and arbitrary executable previews deferred. Native semantic storage/MCP schema expansion and durable typed science media remain larger future work; the queue does not disguise them as one-line Light switches.
