## Mission

Develop a reusable Minamo **Activity Authoring Platform** where GPT, via efficient typed MCP, can publish rich interactive coding challenges, partially completed project templates, deliberate bug hunts, quizzes, mathematical simulations, language-learning exercises, games, interactive tutorials, code walkthroughs and visual investigations, all linked to existing Journeys, Investigations, Library and Notes.

Build a safe **Code/Repository Exchange** that produces actual GitHub/local Windows/Kali starter artefacts with tests, imports exact commit/diff/test evidence and recovers progress across fresh GPT conversations without equating successful execution with learner knowledge.

Build a **Learning Atlas** with semantic Journey routes, a cross-domain Library constellation, evidence/decision timeline, project-centric artefact map and optional owner-licensed tldraw freeform canvas, all faithfully derived from existing data rights and user-authored relationships.

Research dozens of ecosystem candidates the owner supplied and independently discover more. Prefer tested dormant integration infrastructure and representative executable demos over hypothetical future proposals. The initial examples and activity categories are **not a stopping point**.

## Nonnegotiable engineering boundaries

- No main merge, owner production deployment, permissions change, paid new service, actual learner-record mutation or automatic source import from private repositories.
- No arbitrary GPT-authored JavaScript/HTML executed inside owner-authenticated origin. For Sandpack/WebContainers/Strudel, independently prove origin isolation, network/credential safety and terminate/hang control; otherwise bank as external-only.
- No user-supplied repo commits, terminal output or predicted answers reclassified as observed Minamo Runs. No implicit mastery/checkpoints.
- Hidden solutions/oracles must not be reachable from learner DOM/bundle, public files or default MCP. Source/revocation/asset rights apply to retained versions and cached maps.
- Protected CAS, operation identity, owner/generation, recovery/export, Back/Forward, rich Note retention, exact reading anchors, synthetic cleanup and source rights stay intact.
- Avoid unbounded memory, GPU, audio, file sizes, heavy package/eager bundle loads; browser security/Android support are part of the design.
- Reports must clearly distinguish source-only, local tests, live browser, local D1/MCP, authenticated hosted, and physical device acceptance.
