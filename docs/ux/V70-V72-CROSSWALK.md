## What must not be inferred

- V70 “resolved” does **not** mean verified on V86 or every 320px/keyboard/error path.
- A correct current UI state under an owner-only TEST ONLY fixture does **not** imply equivalent behaviour for a real, organic Project or another account.
- A historical deferral is not a failure to implement an authorised request; preserve the intent and explicit acceptance boundary.
- A missing regression assertion is not a production data-loss incident.
- V86 tracing improvements instrument MCP/test-state evidence, not automatically a learner-visible UI redesign.
