# PR27 retrieval adoption decision

**24 October 2026 · selected-scope implementation evidence.** Retain the existing exact/literal Library path for this release. Do not add FTS tables, migrations, readiness metadata or a feature flag. This is the working fallback explicitly authorised by the [selected plan](../IMPLEMENTABLE-PLAN.md#5-retrieval-a-concrete-conditional-engineering-decision), not an uncompleted mandatory feature.

The original spike compared full-question literal matching with FTS. It did not measure the normal GPT baseline of searching a short mechanism/error/technical name. This follow-up measures that omitted comparator before taking on a derived index's rights, restore, readiness and operational burden.

## Reproduce and scope

```sh
python docs/future-learning-review/spikes/pr27-adoption-gate.py
```

[Script](pr27-adoption-gate.py), [complete metrics/cases](pr27-adoption-results.json). Python standard library, in-memory SQLite, no credentials/network/Minamo access. It reuses the original fixed synthetic fixture and adds original unrelated filler to reach 1,000 and 10,000 passages. The 40 existing questions retain their original labels. Preset reformulations were written before the first execution of this script, with at most two short mechanism-focused requests. They were authored by an engineering agent which had read the known fixture, not independently generated by an installed GPT for an unknown corpus; this is an optimistic but useful feasibility comparator.

No expected answer identifier controls a request or early exit. Both reformulated strategies execute the same fixed requests and inspect up to five Article candidates per request. Thus their budget is equal to each other (up to ten candidates), but larger than the single-request original-question comparisons. Multi-passage Articles are grouped before applying the five-Article limit. All strategies keep the same exact-first alias path.

The literal SQL seam resembles the current substring matcher, but this script does **not** execute production `queryLibrary`, current-rights projection, HTTP or MCP. SQLite VM progress samples approximate instruction work; they are not D1 billable `rows_read`, CPU bills or hosted latency. Five warm repeats measure each prescribed request sequence.

## Observed comparison

| Strategy | Useful labelled destination | No-answer cases returning candidates | Mean requests | Mean returned Article candidates | Mean response bytes |
| --- | --- | --- | --- | --- | --- |
| Literal, original question | 16/33 | 0/7 | 1.000 | 0.400 | 88.4 |
| FTS AND/local score, original question | 24/33 | 0/7 | 1.000 | 0.625 | 149.8 |
| Literal, fixed mechanism reformulation | 33/33 | 0/7 | 1.475 | 0.950 | 333.7 |
| FTS AND/local score, same reformulation | 33/33 | 0/7 | 1.475 | 0.925 | 330.3 |

These quality/request/payload results were identical at both scales. The three selected entry-point groups—finding a reference, practical work/evidence, and creating/revising/reusing knowledge—each recovered all three labelled destinations with either reformulated strategy. They test discovery steps, not complete learning workflows or educational outcomes.

| Scale | Reformulated literal warm median / p95 | Reformulated FTS warm median / p95 | Mean approximate VM instructions, literal / FTS |
| --- | --- | --- | --- |
| 1,000 passages | 0.781 / 1.522 ms | 0.030 / 0.093 ms | 17,640 / 222 |
| 10,000 passages | 8.993 / 19.383 ms | 0.033 / 0.097 ms | 175,140 / 280 |

Timings are a single local run and vary on rerun. FTS has a substantial scan-work advantage here; this is real evidence in favour of investigating it when actual corpus/query work makes that advantage valuable. It does not establish hosted MCP savings or justify a specific production budget.

Checks also preserved all eight case/punctuation-sensitive exact queries, excluded ineligible/other-owner/old-generation canaries, and kept candidate order unchanged after adding 150 other-owner plus 150 old-generation rows. Several passages belong to the same Article and do not crowd out separate Article results. These simplified SQL checks do not prove Minamo's rights/recovery/index lifecycle.

## Decision and integrated consequence

The adoption gate is not passed for this release:

- Compared with competent targeted reformulation, FTS showed **no additional useful labelled destination** in this bounded fixture and did not reduce the prescribed request count.
- The raw-question gain remains useful for a learner typing longer questions directly into the web Library. Retaining literal search therefore leaves that specific limitation in place; it is not a claim that current discovery is ideal.
- At large scale FTS sharply reduced local scan work, but actual hosted latency/row work, low-selectivity candidate completeness and publication/rights/generation/restore/readiness interactions remain unverified. Unrelated filler models scan scale, not a diverse realistic Library or useful ranking under many near-matching resources.
- Adding production FTS merely to repeat its local result would create lifecycle work without establishing a needed learning benefit in the selected normal GPT workflow. No semantic service or broad OR fallback is substituted.

Keep exact aliases and useful bounded literal results. In normal authoring/tutoring, a no-hit full question is a reason to try a purposeful mechanism/error phrase and read promising exact resources, not proof the topic is absent. Preserve question meaning when reformulating; an unknown parcel-return question must not become a function-return answer. This guidance is not a required two-search ceremony or permission to fetch every record.

The selected workspace, personal rediscovery, continuity and future-authoring changes remain mandatory and independent of this decision. Personal work must not be added to an Article index for convenience. No production search code or storage was modified by this experiment. Future adoption would require the already specified current-rights/index lifecycle and hosted end-to-end evidence; this receipt adds no separate feature backlog.
