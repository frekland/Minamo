Return values and display effects

A function's returned value can be used by its caller. Printing is a separate effect. A displayed number does not show what the call returned.

function double(value) {
  return value * 2;
}
const answer = double(3);
console.log(answer);

The predicted display is 6. The assignment receives the returned number before the display call.

Inspect a missing return

A function that only prints can leave its caller with undefined. Inspect the result of the call separately from what it displayed.
